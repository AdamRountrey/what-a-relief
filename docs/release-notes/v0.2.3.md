# what-a-relief v0.2.3

## Review Rejected Inverse Candidates

- Finite Mitsuba candidates that fail automatic validation are now retained in
  `inverse/unvalidated_candidate/`, separately from the guarded inverse outputs.
  The default inverse height still retains the baseline on rejection.
- Retained products include floating-point height and correction, height-derived
  normals, hillshade, and an inspection PLY. Candidate filenames, a PLY warning,
  and `candidate.json` make the failed-validation status explicit.
- GUI completion offers to open an offline comparison report. Choose height,
  RGB or X normals, hillshade, or mean training renders, and compare baseline
  and candidate side by side or individually. A warning acknowledgement reveals
  candidate file links; it does not accept or promote the candidate.
- Comparison heights and before/after training renders use shared display
  ranges. Rejection messages now include the decision and review location.
- Accepted runs do not create a duplicate candidate folder. Nonfinite candidate
  geometry is not exported. Reusing an output folder replaces the previous
  inverse results, including any candidate and report.

## Scientific Scope

This is a retention and review change, not a new reconstruction method. Solver
settings and acceptance thresholds are unchanged. A lower image-fit loss or
closer agreement with the photometric-normal prior does not establish physical
height or normal accuracy. Candidate normals are derivatives of candidate
height, not the original photometric normal map. Candidate PLY files are open
inspection surfaces in pixel coordinates, not millimeter-calibrated printable
solids. Keep the JSON provenance with any candidate files used for investigation.

Earlier rejected runs must be rerun to generate candidate files. Existing
outputs are not retroactively recovered. See the
[method and interpretation notes](https://github.com/AdamRountrey/what-a-relief/blob/v0.2.3/docs/algorithm.md)
and [test coverage](https://github.com/AdamRountrey/what-a-relief/blob/v0.2.3/docs/validation.md).

## Windows Downloads

- `what-a-relief-0.2.3-setup.exe`: normal application installer.
- `what-a-relief-0.2.3-portable-windows.zip`: application, DLLs, models, and docs.
- `what-a-relief-0.2.3-mitsuba-backend-setup.exe`: optional self-contained Mitsuba
  backend. Use the matching application and add-on for inverse refinement.
  Ordinary photometric-stereo runs do not require the add-on.

The backend still includes private Python and official LLVM; users do not need
Python or Anaconda installed. Close running application windows before upgrading.
Installers are unsigned, so Windows may display a publisher/SmartScreen warning.
Source images and user projects are not included in the release packages.
