# what-a-relief v0.2.4

## Single-Component Printable Meshes

- Printable PLY export now always keeps the largest edge-connected top surface
  after mesh-step sampling. Disconnected islands and unused vertices are removed.
- Surface size is ranked by projected XY area, not slope magnitude. Ties keep
  the first patch in image order. Downsampling-created separations are handled
  as well as exclusions already present in the geometry mask.
- Point-only contacts are trimmed to avoid nonmanifold vertical edges. The
  retained surface determines the base elevation, bottom faces, and side walls;
  extreme heights on discarded islands no longer affect the base.
- The GUI printable-export label now says "largest component only", and
  processing messages report removed top triangles and samples.

## Scope and Validation

Smart hole filling remains optional and unchanged. It can be enabled separately
to synthesize enclosed missing surface regions for printing. Component cleanup
does not invent bridges between disconnected pieces. Use a smaller mesh step
when thin features are being disconnected by sampling.

These changes apply only to `printable_surface.ply`. Normal maps, height maps,
and the regular open `surface.ply` are unchanged. This is printable topology
cleanup, not a claim of improved measurement or reconstruction accuracy. Older
PLY files must be regenerated to receive the fix.

Regression tests cover separate islands, unused vertices, point contacts,
pinched boundaries, circular vertex fans, downsampling-severed bridges, and 24
deterministic irregular masks. They check connectivity, closed and consistently
oriented edges, retained surface size, base elevation, and unchanged scientific
outputs with smart filling on and off. The release build runs all six application
CTest gates before packaging.

## Windows Downloads

- `what-a-relief-0.2.4-setup.exe`: normal application installer.
- `what-a-relief-0.2.4-portable-windows.zip`: application, DLLs, models, and docs.
- `what-a-relief-0.2.4-mitsuba-backend-setup.exe`: optional self-contained Mitsuba
  backend. The backend algorithms and pinned dependencies are unchanged in this
  release; the add-on is not required for printable mesh export.

Close running application windows before upgrading. Installers are unsigned,
so Windows may display a publisher/SmartScreen warning. Source images and user
projects are not included in the release packages.
