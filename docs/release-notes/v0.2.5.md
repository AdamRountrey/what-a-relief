# what-a-relief v0.2.5

## Input Response and Robust Normal Estimation

- Automatic input-response handling recognizes supported sRGB/linear metadata
  in JPEG, PNG, and classic TIFF. Untagged JPEGs are assumed sRGB; other untagged
  formats are assumed linear. Explicit overrides remain available. Unsupported
  or malformed recognized color metadata is reported rather than silently
  interpreted as calibrated linear data.
- The robust normal solver uses a continuous pseudo-Huber/Cauchy fit instead
  of discrete competing normal hypotheses. This reduces abrupt normal changes
  under small intensity perturbations, without spatial normal smoothing.
- Integer RGB clipping is detected before luminance conversion. Near-clipping
  measurements are downweighted; a narrow transition admits weak measurements
  gradually above the low-signal cutoff. Alpha is not treated as image intensity.
- Residual-scale estimation uses the same input reliability as fitting, so a
  barely admitted observation no longer receives a full scale vote. The run
  manifest records estimator `adaptive_pseudo_huber_cauchy_v2` and convergence.
- No additional robust-solver choices or tuning controls were added to the GUI.

## Validation and Limitations

The seven application CTest suites include automatic-response tests, synthetic
normal recovery, encoded sensor-noise and exposure-boundary cases, three committed
Mitsuba-rendered scenes, output/mesh tests, and end-to-end workflows. Existing
rendered accuracy and shadow/highlight classification gates remain in place.

In the controlled eight-light glossy cutoff test, a 5.15-degree discontinuity
was reduced below 0.00001 degrees. In a separate 40-light real-photo one-code
perturbation test, p99 normal variation fell from 2.76 to 1.94 degrees and the
largest change from 9.06 to 4.26 degrees, retaining all sampled pixels. Those
photo measurements test sensitivity, not ground-truth reconstruction accuracy.

Robust fitting does not universally beat least squares. Some rendered regions
and marginal-pixel coverage regress slightly, while broad gloss, black glossy
surfaces, uncalibrated light brightness, and image processing can still bias
normals. Noise constants are engineering heuristics, not camera calibration.

Relight and the authors' robust-photometric-stereo implementation informed the
comparison. Their code is not incorporated into the application or installer.
Temporary comparison checkouts and generated runs were removed; numerical
summaries and developer reproduction tools remain. The developer tools are
not runtime dependencies or installation requirements.

## Windows Downloads

- `what-a-relief-0.2.5-setup.exe`: application installer.
- `what-a-relief-0.2.5-portable-windows.zip`: application, DLLs, models, and docs.
- `what-a-relief-0.2.5-mitsuba-backend-setup.exe`: optional self-contained
  inverse-rendering backend. Its pinned dependencies and worker algorithms are
  unchanged. The normal input handoff avoids decoding sRGB a second time.

Close running application windows before upgrading. Installers are unsigned
and may trigger a publisher/SmartScreen warning. The application and optional
backend install separately; users do not need to install Python or Anaconda.
