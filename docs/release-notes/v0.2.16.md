# what-a-relief v0.2.16

## Calibration and Lighting

- A printable, dimensioned checkerboard can calibrate pixel pitch and a fixed
  microscope working plane. Calibration is bound to the image dimensions and
  optical setup and records coverage and fit residuals; it is not presented as
  a general camera-intrinsic calibration.
- Calibrated specimen stacks can estimate effective relative light/exposure
  gains from diffuse-range pixels. Spatial-consistency, normal-diversity,
  correction-range, and held-out-prediction gates retain equal gains when the
  estimate is not sufficiently supported. Checkerboard brightness acts only as
  a weak prior because specimen exposures can change between captures.
- Calibration, gains, quality decisions, and copied calibration data are
  recorded in project manifests and restored for compatible reruns.

## Sphere and Height Workflow

- The highlight sphere may be marked in any photograph in the registered set.
  Page Up and Page Down change the displayed photograph; only one image needs
  to be marked.
- Sphere geometry now uses at least five well-spaced circumference points with
  circle-fit residual and angular-coverage checks. Highlight extraction reports
  connected-component, saturation, rim, and centroid-quality failures instead
  of silently producing a questionable light vector.
- Cast-shadow refinement retains only decision-relevant products by default and
  reports whether it was applied, the mismatch improvement, and correction RMS
  directly in the completed GUI session.

## Inverse Rendering and Windows Reliability

- The optional Mitsuba worker has stronger light-support selection, material
  refitting, normal consistency, withheld-light validation, rejected-candidate
  retention, and source-grid output checks. A source-built Dr.Jit Core patch
  prevents the identified large-CUDA-reduction division-by-zero failure.
- The experimental absolute-height Ultra path is capped at a 1024-pixel fitting
  grid and remains in the CLI, project format, worker, and test suite for
  controlled experiments. It is no longer offered in the GUI quality dropdown;
  the GUI exposes Preview, Standard, and High detail only.
- Larger-than-grid fitting masks are now safely resampled when exporting an
  absolute-height candidate. Live normal/hillshade previews are proportionally
  reduced to the GUI decode limit, so they appear every five iterations instead
  of being silently rejected.
- The processing window remains responsive, progress no longer flickers as a
  misplaced lower-left control, and failure or cancellation retains the current
  settings for correction and rerun.

## Validation and Limits

The production application build passed all nine CTest suites. The optional
backend package passed 26 numerical tests, network-safe progress and preview
tests, differentiable shadow finite-difference checks, matched-model recovery
and truth-start rejection checks, extracted-runtime LLVM probing, and the CUDA
device probe.

These are software and matched-model regression gates, not metrological
validation. Inverse rendering remains experimental: image-fit improvement does
not prove physical-height improvement, particularly for dark glossy specimens
without informative moving shadows. Ultra's 1024-pixel cap does not establish
accuracy at that scale.

## Windows Downloads

- `what-a-relief-0.2.16-setup.exe`: application installer.
- `what-a-relief-0.2.16-portable-windows.zip`: portable application, runtime
  libraries, models, and documentation.
- `what-a-relief-0.2.16-mitsuba-backend-setup.exe`: optional self-contained
  Mitsuba/Dr.Jit runtime. Install the application first and this add-on second.

Close running application windows before upgrading. The installers are unsigned
and may trigger a publisher or SmartScreen warning. Existing output projects are
not modified by installation. A separate Python or Anaconda installation is not
required.
