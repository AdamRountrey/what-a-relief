# what-a-relief v0.2.7

## Persistent Project Workflow

- The application remains open after a completed or failed run. The new **File**
  menu can start a new project, open a completed project, open the current output
  folder, review a retained inverse candidate, or exit.
- Opening a completed project's `run_manifest.json` restores its ordered images,
  calibration, ring geometry, scale, crop and sphere, input response, height and
  printable-mesh settings, RTI choices, and experimental refinement settings for
  review or rerunning. Backend executable and worker overrides are never restored
  from project files.
- Interactive specimen selections are saved separately from the final
  height-validity mask so a reopened project does not silently use height-only
  exclusions as its normal-solve mask.
- GUI reruns use a fresh output directory and preserve earlier completed results.
  New Project resets image-dependent choices, while processing errors return to a
  usable application window instead of terminating the program.

## Progress, Preview, and Windows Experience

- Processing runs on a background worker while the main window remains
  responsive. The Progress tab shows the current stage, detailed output-writing
  messages, elapsed time, a current-stage ETA when it can be estimated, and an
  activity indicator for stages without a meaningful work count.
- The normal solver reports completed image rows. Mitsuba reports iterations and
  estimated time remaining, with provisional normal/hillshade previews every five
  iterations and at the final iteration when live previews are enabled.
- The Advanced tab remains visible after completion. Repeated runs, cancellation,
  deferred exit, and error recovery are guarded against reentrant processing and
  stale worker updates.
- Graphical launches no longer open a Windows terminal behind the application.
  Command-line use remains available with the existing options.

## Validation and Limits

Two new application suites cover project persistence and the Windows GUI
lifecycle. Tests exercise moved project folders, malformed and legacy manifests,
fresh rerun destinations, repeat runs, cancellation, deferred exit, error
recovery, Advanced-tab visibility, progress monotonicity, ETA behavior, and
provisional preview display. Mitsuba numerical, progress-file, and real CPU
renderer checks cover preview orientation, spacing, iterations 5/final, and
retention of the existing reconstruction-improvement and rejection gates.

Progress callbacks are observational and are checked to leave reconstructed
normal and albedo products bit-identical. ETA values are estimates for the current
stage, not promises for the complete pipeline. Mitsuba previews are provisional
and do not bypass withheld-light, normal-consistency, displacement, or other
acceptance checks. This release does not make new reconstruction-accuracy or
metrology claims.

The production build passed all nine CTest suites. An independently extracted
main-installer payload completed the calibrated end-to-end workflow with version
`0.2.7`, complete manifest status, and full solve coverage. The optional backend
package passed its numerical, network-progress, preview, real CPU renderer,
positive reconstruction, rejection, and extracted-runtime probe gates.

## Windows Downloads

- `what-a-relief-0.2.7-setup.exe`: application installer.
- `what-a-relief-0.2.7-portable-windows.zip`: application, DLLs, models, and docs.
- `what-a-relief-0.2.7-mitsuba-backend-setup.exe`: optional self-contained
  inverse-rendering runtime.

Close running application windows before upgrading. Installers are unsigned and
may trigger a publisher or SmartScreen warning. Existing project outputs are not
modified by installation. Users do not need a separate Python or Anaconda
installation.
