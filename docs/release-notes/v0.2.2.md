# what-a-relief v0.2.2

## Less Output Clutter

- Nine robust summary images are now opt-in instead of being written on every
  calibrated robust run. Enable **Write additional robust diagnostic images
  (summary and per-light)** on the Advanced tab, or use `--specular-diagnostics`.
- Default image products remain RGB/X/Y/Z normals, upper-left hillshade,
  albedo, residual, valid mask, and liquid metal. Height, meshes, RTI, neural
  fusion, and advanced-refinement outputs still follow their selected options.
- Repeat-run cleanup removes stale generated diagnostics. Disabling diagnostic
  export does not change the core normal and visualization products.

## Reconstruction And Reliability

- Corrected pixel-center-to-edge slope discretization, DCT boundary terms,
  and padding in height integration. Both fast and masked robust integration
  now use consistent edge targets; original photometric normals are preserved.
- Improved robust shadow/highlight handling, unsupported-pixel reporting,
  saturation validity, local conditioning, and test coverage from the
  September scientific/code review. Unsupported geometry is not force-fit.
- Hardened cast-shadow refinement's finite-source/datum conventions,
  training/withheld-light checks, compact observation storage, and diagnostics.
- Added full-precision classical photometric normals as a confidence-weighted
  constraint on optional Mitsuba inverse refinement. Finer height controls,
  alternating material refits, training-plus-prior checkpoint selection, and
  independent-seed validation improve the tested height reconstruction.
- The optional backend pins official LLVM 15.0.7 for the tested Windows CPU
  runtime and retains CUDA support. It includes its own Python, Mitsuba,
  Dr.Jit, and NumPy; no system Python or Anaconda installation is required.

## Scientific Limits

The independent eight-light curved-scene test shows accepted global height
improvement on CPU and CUDA, including a rotated-light CUDA capture. Original
photometric normals remain more accurate than inverse-derived normals, and
some local height regions still regress. Inverse outputs are separate and
experimental, not calibrated height metrology. No general BRDF, camera, lens,
or source calibration is claimed. See
[the complete test record](../inverse-pipeline-test.md) and
[method references](../algorithm.md).

## Windows Downloads

Local release verification passed the six application CTests, staged backend
numerical and live CPU renderer tests, installer extraction, and portable
content checks. The extracted application/backend also passed the independent
eight-light pipeline on CPU and the rotated-light pipeline on CUDA. GitHub
Actions rebuilds and verifies the published assets separately.

- `what-a-relief-0.2.2-setup.exe`: normal application installer.
- `what-a-relief-0.2.2-portable-windows.zip`: application, DLLs, models, and docs.
- `what-a-relief-0.2.2-mitsuba-backend-setup.exe`: optional self-contained inverse
  backend. Update both the application and this add-on when using inverse
  refinement. Ordinary photometric-stereo runs do not require the add-on.

Installers are unsigned; Windows may display a publisher/SmartScreen warning.
Close running application windows before upgrading. Source images and user
projects are not part of the release packages.
