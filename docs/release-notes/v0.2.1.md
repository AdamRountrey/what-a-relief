# what-a-relief v0.2.1

This release strengthens scientific safeguards, test coverage, performance, output reliability, and optional inverse-rendering support.

## Scientific Correctness

- Use exact selected sRGB decoding and one shared image-stack intensity scale.
- Match named calibration rows to images and reject ambiguous or ill-conditioned lighting.
- Allow GUI users to confirm a positional fallback for older `lights.csv` files whose recorded image names no longer match.
- Apply inverse-square attenuation in the nearby isotropic ring-light model.
- Separate dark residuals from highlight diagnostics and make three-observation fallback explicit.
- Keep unsupported neural predictions outside the fused validity mask.
- Interpret GeoTIFF pixel scale only with supported declared linear units.
- Make height flattening choices explicit: none, plane, radial, or quadratic.
- Add optional guarded broad-height refinement from coherent cast-shadow boundaries for either sphere-calibrated directional lights or the near-field ring model. It affects only height and meshes, uses confidence-weighted shadow and anti-shadow evidence with low-order corrections and a normal prior, validates exact candidate steps against each withheld light, and preserves height exactly when rejected.
- Add an explicit near-field reference-surface Z, an effective finite LED diameter with sampled penumbra probabilities, and observability, edge-support, occluder-support, evidence-confidence, and per-light probability audits. Ring-only parameters remain inactive for directional calibration.

## Reliability And Speed

- Show the exact `what-a-relief 0.2.1` version in the setup-window title and label height-only leveling as Height Drift Correction.
- Add deterministic synthetic and end-to-end CTest gates before Windows packaging.
- Correct Deep Zoom pyramid levels and test reconstructed coefficient images.
- Use checked output writes, transactional RTI replacement, and versioned run manifests.
- Preserve calibration and masks reused from an output folder and reject destructive input collisions.
- Verify installer contents and stage portable archives from a runtime whitelist so models are present and local inputs or smoke outputs are excluded.
- Parallelize calibrated solves; the fixed development benchmark was about seven times faster with an unchanged checksum.
- Batch PFM and PLY writes, share mesh topology, replace printable-mesh edge hashing with compact grid bookkeeping, and parallelize independent image and RTI work; the fixed output benchmark was about eleven times faster.
- Compile the standalone executable used by the installer and portable archive with MSVC release optimization. A fixed five-image workflow was about 3.8 times faster than the formerly unoptimized package build.
- Parallelize radiometric cleanup, visualization generation, height-solver preparation and flattening, RTI coefficient fitting, and Deep Zoom or webRTIViewer tile encoding without changing the ordered robust-height iteration.
- Exit a canceled GUI setup quietly instead of presenting it as an application error.
- Remove the redundant padded PS-FCN input stack and report dense input memory requirements.
- Add optional slope-guided filling of enclosed printable-surface gaps, with a separate synthesized-pixel audit mask.
- Write cast-shadow correction, constraint, mismatch, per-light visibility audits, and an explicit manifest decision for every requested shadow-refinement run.
- Package the optional Mitsuba inverse-rendering backend as a separate self-contained Windows installer with private CPython 3.13.13 and LLVM 18.1.6 runtimes, pinned wheel hashes, CPU and CUDA probes, and automatic application discovery. Users do not install Python, Conda, pip, or LLVM.
- Transfer the already decoded linear luminance stack to Mitsuba as temporary 16-bit PNG observations instead of asking the renderer to reopen source files. This adds TIFF and vendor-format compatibility, preserves common-scale photometry, and removes the temporary stack after processing.
- Permit atomic Mitsuba progress-file replacement while the Windows GUI polls it, with a retrying in-place fallback for SMB servers that reject replacement of an open file. Scientific result files retain their checked or transactional writes.
- Proxy renderer-facing bitmap reads, optimization-mesh loading, and bitmap writes through local temporary paths when an inverse job is stored on a Windows network share. Completed audit files remain in the selected output folder; this avoids Mitsuba `FileStream` UNC-path failures without changing numerical products.
- Migrate installations and shortcuts made under the former `What A Relief` folder name to the canonical `what-a-relief` location.

## Interpretation

Robust fitting addresses sparse corrupted observations, not general glossy-surface reconstruction. The broad-gloss synthetic fixture still has about 20.5 degrees mean normal error; the specular cue is a diagnostic, not a repair. Physical XY scale does not by itself validate absolute height. Cast-shadow acceptance means improvement under a simplified height-field visibility model, not proof of lower physical height error. See [validation criteria](../validation.md) and [algorithm details](../algorithm.md).
