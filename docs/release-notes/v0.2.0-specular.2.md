# what-a-relief v0.2.0-specular.2

Experimental pre-release from the `experiment/specular` branch.

## Highlights

- Redesigned the setup GUI into Project, Lighting, Geometry, Processing, Outputs, and Advanced tabs.
- Added GUI progress reporting during long processing and export stages.
- Added optional specimen height masks for height preview and mesh export, without changing normal, albedo, residual, or relighting outputs.
- Added scale-line entry in the GUI and TIFF pixel-scale reading for workflows that need physical XY scale.
- Added a near-field ring-light model with radius, height, and pixel scale in millimeters.
- Added optional PS-FCN-based neural normal fusion for calibrated 3- to 25-image captures.
- Added `hillshade_ul.png`, a cartographic-style upper-left hillshade derived from the solved normal field.
- Added RTI export options, including image, DeepZoom, and webRTIViewer-compatible layouts.
- Added optional watertight printable PLY export with a flat base and closed side walls.

## Output Changes

- Normal-map outputs now include `hillshade_ul.png`.
- Neural-fusion runs write `classical_*`, `neural_*`, and `fused_*` normal and hillshade comparison outputs.
- Height-enabled runs write `height_mask.png`.
- Standard PLY export remains an open inspection surface at `surface.ply`.
- Printable export writes `printable_surface.ply` and requires physical XY scale.
- RTI export writes an `rti/` folder in the selected output directory.

## Important Notes

- This is an experimental branch build, not the conservative stable line from `main`.
- Neural fusion is intended for visualization-oriented normal products.
- Height and mesh outputs remain qualitative relative products unless the imaging geometry and scale are independently validated.
- Printable PLY export is intended to be watertight, but slicer preview and scale checks are still recommended before printing.
- The `webrti` RTI layout targets the `info.xml` plus component-tile structure used by webRTIViewer.

## Verification

- Windows direct vcpkg build completed successfully.
- Printable PLY smoke export completed with TIFF scale auto-detection.
- A binary PLY edge-count check reported `bad_edges=0` for the smoke-test printable mesh.
- Invalid negative pixel scale is rejected at argument parsing.
- `ctest` runs against the build directory, but this release does not yet include registered CTest tests.
