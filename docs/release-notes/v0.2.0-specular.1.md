# what-a-relief v0.2.0-specular.1

Experimental pre-release from the `experiment/specular` branch.

## Highlights

- Adds optional PS-FCN-based neural normal fusion for calibrated 3- to 25-image captures.
- Writes separate classical, neural, and fused normal-map outputs for direct comparison.
- Keeps height preview and PLY export on the classical geometry path to avoid exaggerated fused geometry.
- Bundles the ONNX neural models and their third-party licensing notices in repo, runtime packages, and installer builds.
- Updates the documentation to describe the calibrated, uncalibrated, near-field, and neural-fusion workflows more clearly.

## Important Notes

- This is an experimental branch build, not the conservative stable line from `main`.
- Neural fusion is intended for visualization-oriented normal products.
- Height and mesh outputs remain qualitative relative products unless the imaging geometry and scale are independently validated.
